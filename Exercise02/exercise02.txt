3. EXPLANATION
-----------------------
MPI_Reduce with MPI_SUM combines separate contiguous ranges. Long long prevents 32-bit overflow. The reference is N*(N+1)/2 with N=10000000. Remainders are distributed among the first ranks.

4. DISTRIBUTED RUN
-----------------------
MPI environment: Amazon Linux 2023, Open MPI 4.1.2.
Enable /usr/lib64/openmpi/bin in PATH and libraries in LD_LIBRARY_PATH.
Set OMPI_MCA_plm_rsh_agent to SSH using ~/.ssh/lab08_mpi.
Install executable at the same absolute path on both nodes.
